# الكاتيجوري (Category) — مصروف — تحديث: رجعت للقراءة فقط

**Base URL:** `https://finance-tracker-five-liart.vercel.app`

> شكل الـ Response العام موجود بالتفصيل في ملف `login-register.md`.

---

## ⚠️ تغيير عن آخر نسخة بعتّهالك

في الكولكشن اللي قبل ده كانت الكاتيجوري بقت CRUD كامل (إنشاء/تعديل/حذف مملوك للمستخدم). **في النسخة الجديدة دي، اتشالوا التلاتة endpoints دول (Create / Update / Delete)**، ورجع الفولدر لـ **قراءة بس** زي أول نسخة كانت عندنا:

---

## 1. عرض كل التصنيفات — `GET /category`

**Header:** `authorization: <access_token>`

**Response (نجاح):**
```json
{
  "message": "Done",
  "success": true,
  "status": 200,
  "data": [
    { "_id": "6a7b2544b7e711374175c0a8", "name": "طعام ومشروبات", "type": "expense" },
    { "_id": "6a7b2544b7e711374175c0ad", "name": "ادخار للسفر", "type": "savings" }
  ]
}
```

## 2. عرض تصنيف واحد — `GET /category/:id`

**Header:** `authorization: <access_token>`

**قواعد:**
- التصنيف لازم يكون موجود، وإلا `404`.
- المستخدم العادي يقدر يشوف تصنيفه هو بس؛ لو حاول يشوف تصنيف مستخدم تاني → `403`.
- الـ Admin يقدر يشوف أي تصنيف.

**Response (نجاح):**
```json
{
  "message": "Done",
  "success": true,
  "status": 200,
  "data": { "_id": "6a7b2544b7e711374175c0a8", "name": "طعام ومشروبات", "type": "expense" }
}
```

## ملاحظات للأجنت

- **لا تبنيش شاشة "إضافة/تعديل/حذف تصنيف"** — دي رجعت غير متاحة للمستخدم العادي في النسخة الحالية من الـ API. لو كان فيه شغل اتعمل عليها بناءً على النسخة اللي قبل دي، وقّفيه لحد ما يتأكد الوضع النهائي مع الباك إند.
- التصنيفات هنا للقراءة والاختيار بس (زي اختيار تصنيف عند إضافة معاملة أو ميزانية) — مصدرها ثابت من الباك إند حاليًا.
- بما إن ده اتغيّر أكتر من مرة (ثابت → قابل للتعديل → ثابت تاني)، يُفضّل تتأكدي مباشرة مع الباك إند إيه الوضع النهائي المستقر قبل ما تقفلي شاشات الحساب/الإعدادات، بدل ما تعتمدي على آخر كولكشن بعتّهولك بس.
