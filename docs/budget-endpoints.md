# الميزانية (Budget) — مصروف

**Base URL:** `https://finance-tracker-five-liart.vercel.app`

> شكل الـ Response العام (نجاح/فشل) موجود بالتفصيل في ملف `login-register.md` — نفس الشكل ساري هنا. كل الـ endpoints هنا محتاجة Header:
> `authorization: <access_token>`
>
> ملحوظة: الـ Postman collection معندهاش نص وصف (description) مكتوب لفولدر الـ Budget زي باقي الفولدرز، فالتفاصيل هنا مبنية على الـ request/response الفعليين في الكولكشن — لو فيه قاعدة إضافية (زي حد أقصى للمبلغ، أو منع تكرار ميزانية لنفس التصنيف في نفس الشهر) لازم تتأكدي منها مع الباك إند وقت التنفيذ.

---

## 1. إنشاء ميزانية

`POST /budget`

**Header:** `authorization: <access_token>`

**Body:**
```json
{
  "category": "6a7b2544b7e711374175c0a8",
  "amount": 3000,
  "month": "2026-07"
}
```

| الحقل | النوع | إلزامي | الوصف |
| --- | --- | --- | --- |
| category | string (ObjectId) | ✅ | ID تصنيف موجود فعلاً (من `GET /category`) |
| amount | number | ✅ | سقف الميزانية المطلوب للتصنيف ده في الشهر ده |
| month | string | ✅ | صيغة `YYYY-MM` (زي `2026-07`) |

**Response (نجاح) — شكل تقريبي:**
```json
{
  "message": "Done",
  "success": true,
  "status": 200,
  "data": {
    "_id": "6a7c3b1a99110ab52f875c10",
    "category": "6a7b2544b7e711374175c0a8",
    "amount": 3000,
    "month": "2026-07"
  }
}
```

---

## 2. عرض الميزانية

`GET /budget`

**Header:** `authorization: <access_token>`

### Query Parameters

| Parameter | النوع | إلزامي | الوصف |
| --- | --- | --- | --- |
| month | string | ❌ (على الأغلب) | صيغة `YYYY-MM` — المثال في الكولكشن باعتها صراحة، فلو محتاجة تتأكدي هل ليها افتراضي (زي الشهر الحالي) لو اتشالت، اسألي الباك إند لأن مفيش وصف موضّح زي باقي الـ endpoints |

**مثال:**
```
GET /budget?month=2026-07
```

**Response (نجاح) — شكل تقريبي:**
```json
{
  "message": "Done",
  "success": true,
  "status": 200,
  "data": [
    {
      "_id": "6a7c3b1a99110ab52f875c10",
      "category": { "_id": "6a7b2544b7e711374175c0a8", "name": "طعام ومشروبات", "type": "expense" },
      "amount": 3000,
      "month": "2026-07"
    }
  ]
}
```

## ملاحظات للأجنت

- **مفيش endpoint حذف أو تعديل ميزانية في الكولكشن حاليًا** — بس إنشاء وعرض. الباك إند هيضيف endpoint التعديل **لاحقًا** (متأكد إنه جاي، بس لسه معملوش). لحد ما يوصل:
  - **لحل مؤقت:** ابني شاشة الإنشاء بس دلوقتي، وسيبي "تعديل الميزانية" كزرار معطّل أو مخفي مؤقتًا، أو نفّذيها بمنطق Upsert (إنشاء ميزانية جديدة تحل محل القديمة لنفس التصنيف/الشهر) **لو** أكدلك الباك إند إن ده فعلاً السلوك الحالي للـ `POST /budget` — لسه محتاجة تتأكدي من النقطة دي.
  - **مهم:** خلي بنية الكود (الـ component بتاع فورم الميزانية) جاهزة إنها تستقبل وضع "تعديل" بسهولة لما الـ endpoint يوصل، عشان متضطريش تعيدي بناء الشاشة من الصفر.

- **الميزة دي دلوقتي داخل نطاق المرحلة الحالية (مش مؤجلة)** — بناءً على إن الباك إند بيدعمها فعلاً. الشاشة المطلوبة:
  1. **شاشة إعداد الميزانية:** فورم لكل تصنيف (اختيار من `GET /category`) + مبلغ شهري + الشهر → `POST /budget`.
  2. **شاشة عرض ومقارنة:** لكل تصنيف، اجيبي **المصروف الفعلي** من `GET /transaction/summary?month=YYYY-MM` وقارنيه بـ **سقف الميزانية** من `GET /budget?month=YYYY-MM` لنفس التصنيف، واعرضيهم مع بعض (زي شريط تقدّم: اتصرف كام من سقف كام).
  3. لو المصروف الفعلي قرّب أو عدّى السقف، أظهري تنبيه بصري واضح (لون تحذيري) في الشاشة دي — ده منطق فرونت بحت، مفيش endpoint خاص بالتنبيه نفسه.

- زي باقي الـ endpoints، `month` لازم يتبعت بصيغة `YYYY-MM` بالظبط.
